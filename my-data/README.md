# my-data/ (private)

Everything you put in this folder stays on your computer. Git ignores it (only this README is
tracked), so it is never pushed to GitHub, even if you fork the repo.

Typical contents, created with the skills:

| File | Created by |
|---|---|
| `master-cv.md` (or `.docx`) | You, or the `cv-builder` skill |
| `skill-profile.md` | The `skill-profile-builder` skill |
| `tailored/<company>-<role>.md` | The `cv-builder` skill (tailor mode) |
| `interview-prep/<company>/...` | The `interview-coach` skill |

Before you share anything from here with anyone (including a consultant), remove phone numbers,
home address and anything you would not post publicly.
